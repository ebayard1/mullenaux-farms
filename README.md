# Mullenaux Farms Website

Single-page marketing site for Mullenaux Farms — regenerative pastured-egg partnerships in Arizona.

The entire site is self-contained in `index.html` (HTML, CSS, and JavaScript in one file). No build step or dependencies are required.

## Hosting with GitHub Pages

1. Push these files to a GitHub repository.
2. Go to the repo's **Settings → Pages**.
3. Under "Build and deployment," set the source to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.
5. After a minute or two, your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Local preview

Just open `index.html` in any web browser.
